# Neovim Quick Reference for Note-Taking

## 🚀 Getting Started
- Press `Space` (Leader key) and wait - WhichKey will show you all available commands!
- Type `jj` in insert mode to escape (easier than reaching for Esc)
- Use `Ctrl+S` to save (works in any mode)

## 📝 Essential Note-Taking Commands

### Basic Operations
- `i` - Enter insert mode (start typing)
- `jj` - Exit insert mode (custom shortcut)
- `Ctrl+S` - Save file
- `Ctrl+Q` - Quit
- `Space + w` - Save (alternative)
- `Space + x` - Save and quit

### Obsidian Integration (Space + o)
- `Space + on` - Create new note
- `Space + oo` - Open existing note
- `Space + os` - Search all notes
- `Space + oq` - Quick switch between notes
- `Space + ot` - Today's daily note
- `Space + oy` - Yesterday's note
- `Space + ob` - Show backlinks
- `Space + ol` - Show all links
- `Space + of` - Follow link under cursor
- `Space + or` - Rename current note
- `Space + ow` - Switch workspace

### Navigation Made Easy
- `Ctrl+H/J/K/L` - Move between windows (left/down/up/right)
- `Shift+H/L` - Switch between open files (like browser tabs)
- `]b` / `[b` - Next/previous buffer
- `gg` - Go to top of file
- `G` - Go to bottom of file
- `/text` - Search for "text"
- `n` / `N` - Next/previous search result (auto-centered)

### Useful Features
- `Space + u` - Undo tree (visual undo history)
- `Space + z` - Zen mode (distraction-free writing)
- `Space + tw` - Toggle word wrap
- `Space + tn` - Toggle line numbers
- `Space + sr` - Search and replace

### File Management
- `Space + ff` - Find files
- `Space + fg` - Find text across all files
- `Space + fb` - Find open buffers
- `Space + fr` - Find recent files

## 💡 Pro Tips for Beginners

1. **Start in Normal Mode**: When you open Neovim, you're in "Normal" mode. Press `i` to start typing.

2. **Use WhichKey**: Press `Space` and wait - it shows all available commands with descriptions!

3. **Don't Panic**: If you're stuck, press `Esc` or `jj` to get back to normal mode.

4. **Save Often**: `Ctrl+S` works everywhere. Auto-save is enabled but manual saving is still good practice.

5. **Mouse Works**: You can click and scroll with your mouse while learning keyboard shortcuts.

6. **Visual Mode**: Press `v` to select text, then use commands on the selection.

## 🔧 Markdown-Specific Features

- Checkboxes: `Space + ch` to toggle `- [ ]` / `- [x]`
- Links: `gf` to follow a link under cursor
- Concealment: Markdown syntax is hidden for cleaner viewing
- Word wrap: Enabled by default for comfortable reading

## 🆘 Emergency Commands

- `:q!` - Quit without saving (if you made a mistake)
- `:w` - Save file
- `:wq` - Save and quit
- `u` - Undo last change
- `Ctrl+R` - Redo

## 📚 Learning Path

1. Start with basic editing: `i` to insert, `jj` to escape, `Ctrl+S` to save
2. Learn movement: `h/j/k/l` for left/down/up/right
3. Use Obsidian commands: `Space + o` then explore the options
4. Gradually learn vim motions: `w` (word), `b` (back), `e` (end)
5. Master search: `/` to search, `n` for next result

Remember: You don't need to learn everything at once! Start with the basics and gradually add more commands to your workflow.
